Computer Vision Project

Real-Time Touchless Air Writing Canvas

An intelligent hand-tracking system that turns air gestures into digital writing strokes using OpenCV and MediaPipe. No touch screen or specialized hardware required.

View on GitHub Run Locally
🖐️

Hand Landmark Tracking

Uses MediaPipe Hands framework to calculate 21 distinct 3D landmarks in real time with minimum latency.

✍️

Interactive Canvas

Dynamic virtual canvas drawing with multi-color palettes, stroke thickness adjustments, and gesture-driven clearing.

⚡

High Performance

Optimized image processing pipeline powered by OpenCV and NumPy for smooth, 30+ FPS video stroke mapping.
